Sequence rationale

The order is part of the curriculum.

First understand model behavior and empirical evaluation. Then design agents, context, memory, and tools. Only after that build rigorous graders, statistics, security, platform infrastructure, and modernization-specific evaluation.

01–04Foundations and agent systems: model behavior, eval thinking, orchestration, and typed tool boundaries.
05–08Context and knowledge: repository intelligence, memory, and portable MCP services.
09–13Evaluation design: Task Packs, benchmarks, deterministic graders, LLM judges, and trajectories.
14–16Evaluation science: reliability statistics, failure analysis, and benchmark integrity.
17–21Platform engineering: observability, security, experiment infrastructure, economics, and governance.
22–25Modernization domain: business-rule recovery, architecture, parity, and data migration.
26–27Synthesis: ship the platform and publish reproducible research.
